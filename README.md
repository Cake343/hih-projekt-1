# HiH – Projekt 1: Moje hobby

Strona o fotografii wykonana w ramach projektu z przedmiotu **Hipertekst i Hipermedia** (Informatyka, Politechnika Gdańska, semestr 1, 2026/27).

## Zawartość

- `index.html` – strona główna
- `sprzet.html` – aparaty i obiektywy, tabela porównawcza
- `galeria.html` – galeria zdjęć z podglądem powiększenia (`:target`)
- `kontakt.html` – ankieta (formularz)
- `dziekuje.html` – strona po wysłaniu formularza
- `styles.css` – arkusz stylów (responsywność, animacje)
- `img/` – zdjęcia, `img/min/` – miniatury
